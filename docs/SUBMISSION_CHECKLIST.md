# Submission Checklist

## Scientific package
- [x] Exact correction theorem stated and separated from finite synthetic evidence.
- [x] Legacy claims that contradict the stated operator removed from the core theory.
- [x] Transformation groups and quotient regimes explicitly defined.
- [x] Positive controls, negative controls, adversarial collisions, and discriminant crossing included.
- [x] Exact arithmetic used for discrete claims whenever possible.
- [x] Finite-atlas reconstructibility is explicitly not presented as a universal completeness theorem.
- [x] Code, tables, machine-readable summaries, figures, environment information, and run log supplied.

## Files ready for journal adaptation
- [x] Main manuscript: DOCX + PDF + Markdown + LaTeX source.
- [x] Supplementary appendix: DOCX + PDF + Markdown + LaTeX source.
- [x] Reproducibility package.
- [x] Claim-boundary document.
- [x] Revision map from the legacy theory.
- [x] SHA-256 manifest.

## Items to customize after selecting a journal
- [ ] Journal template and exact reference style.
- [ ] Word/figure/table limits.
- [ ] Repository DOI/URL after archival upload.
- [ ] Journal-specific data/code availability wording.
- [ ] Conflict-of-interest and funding forms required by the publisher.
- [ ] Cover letter and suggested reviewers if requested.

A Q1 outcome is not guaranteed; the package is structured for the rigor, falsifiability, and reproducibility expected of a strong mathematical/computational submission.
